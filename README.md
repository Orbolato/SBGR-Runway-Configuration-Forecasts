# When Do Data-Driven Models Improve Runway-Configuration Forecasts?

Code, public-source processed data, archived results, and provenance documentation for the article

> Vieira, G. L. G. R., Gomes, I. G., Carvalho, L. O., Guterres, M. X., da Silva, E. J.,
> and Caetano, M. *When Do Data-Driven Models Improve Runway-Configuration Forecasts?
> Multi-Horizon Operational Evidence from São Paulo/Guarulhos.* *Journal of Air
> Transport Management*, accepted for publication (2026). Manuscript JATM-D-26-00770.

The study forecasts the runway configuration of São Paulo/Guarulhos International
Airport (SBGR) 15, 30, and 60 minutes ahead from 87,540 fifteen-minute intervals
(January 1, 2022 to June 30, 2024). It compares majority, persistence, climatology,
and a wind rule with logistic regression, random forest, and histogram gradient
boosting, plus XGBoost, LightGBM, and three comparators adapted from published
designs. Models are selected by expanding-window validation in 2023 and evaluated
on a locked January–June 2024 test period.

## Publication status

The article has been accepted for publication in the *Journal of Air Transport Management* (2026). A DOI, volume, and article number had not yet been assigned when this repository was prepared; citation metadata will be updated when those production details become available.

## Repository layout

```
code/
  prepare_data.R      builds the 15-minute interval grid from the five source files
  run_analysis.py     features, temporal validation, all models, calibration, bootstrap,
                      transition and event metrics, robustness analyses; writes the
                      results record, Tables 3-10, the prose macros, and Figures 1-7
  make_figures.py     draws Figures 1-7 from the results record (no refitting)
  verify_outputs.py   checks a rerun against the archived results
data/
  METAR/              exact public-source processed METAR input used in the study
  SIROS/              exact public-source processed arrival/departure schedule inputs
  TATIC/              documentation only; restricted operational records are excluded
results/
  analysis_results.json      archived results record behind every reported number
  figure_data.json           plotted series not held in the record (Figures 4, 5b, 6a)
  figure_source_values.json  values used for the R2 artwork (provenance only)
reproduce.ps1, reproduce.sh  one-command reproduction helpers
```

## Reproduction

### 1. Without the restricted data (tables, macros, and figures)

```bash
python code/run_analysis.py --artifacts-only   # Tables 3-10 and generated_results.tex
python code/make_figures.py                    # Figures 1-7
```

Outputs go to `output/`. The tables and macros are identical, byte for byte, to
those in the submitted R2 manuscript.

### 2. Full rerun from the source records

The three public-source processed METAR/SIROS inputs used in the study are included
under `data/METAR/` and `data/SIROS/`. A full refit additionally requires the two
restricted TATIC files at the paths documented in `data/README.md`, `Rscript` on
the `PATH`, and the R package `data.table`.

```bash
python code/run_analysis.py      # calls Rscript code/prepare_data.R internally
python code/verify_outputs.py
```

The rerun writes `output/analysis_results.json`, `output/figure_data.json`,
Tables 3–10, `generated_results.tex`, and Figures 1–7. `verify_outputs.py` then
compares every numeric value with the archived record in `results/`, and the
tables, macros, and figures with those regenerated from it. Environment variables:

- `SBGR_DATA_DIR`, `SBGR_OUTPUT_DIR`: override `data/` and `output/`.
- `SBGR_GRID_CSV`: path to an interval grid already written by `prepare_data.R`;
  skips the R step. The grid is deterministic, so both paths give identical results.
- `SBGR_NBOOT`: number of day-block bootstrap resamples, for smoke tests only. All
  reported results use the default of 500.
- `LOKY_MAX_CPU_COUNT`: defaults to 8.

Fit times (Table 8) and inference latency are wall-clock measurements. The paper
reports them as indicative magnitudes; they are the only quantities not fixed by
the seed, and `verify_outputs.py` reports them separately.

## Verification status

The public, restricted-data-free reproduction path was verified on October 12, 2026: Tables 3-10 and `generated_results.tex` were regenerated exactly, and Figures 1-7 matched the archived references pixel-for-pixel at 150 dpi using `code/verify_outputs.py`. ## Relation to the revision history

All statistical results were produced by one run of the R1 analysis. The R2
revision changed presentation only: no model was refitted and no number changed.
The accepted manuscript retains those R2 statistical results. This repository merges the two stages into a single pipeline:

- `run_analysis.py` is the R1 analysis script. Its analytical code is unchanged.
  Changes: file paths; R2 table formatting (Table 7 prints the two identical
  60-minute threshold-criterion rows as one; Table 9 cites its section by label);
  figure drawing moved to `make_figures.py`; and the plotted series that the results
  record did not hold are now saved to `figure_data.json`.
- `make_figures.py` draws the R2 figure set. Figures 1, 3, and 4 are unchanged from
  R1. Figures 2, 5, 6, and 7 follow the R2 redraw (former R1 Figure 8 is now
  Figure 6; former Figure 7(b) is now Figure 7; former Figure 5 and Figure 7(a) were
  removed).
- For the R2 artwork, the reliability curve and the monthly series were recovered
  from the R1 vector figures (`figure_source_values.json`, maximum error below
  5e-4). `figure_data.json` holds the same series computed directly by a full rerun.

## Data and code availability

The exact processed METAR (REDEMET) and planned-schedule (ANAC SIROS) inputs used in
the study are included in this repository under `data/METAR/` and `data/SIROS/`.
Their row counts, MD5 checksums used in the analysis, and SHA-256 checksums of the
author-bundle copies are documented in `data/README.md` and `PROVENANCE.md`.
The TATIC TWR movement and runway-use records are restricted operational extracts
that cannot be redistributed; access requires a separate request to NAV Brasil.

The repository's artifact-only reproduction path does not require the source-data
files: it regenerates every reported table, macro, and figure from the archived
numerical records in `results/`. Users who separately obtain authorized TATIC
records can combine them with the included METAR/SIROS inputs to run the full refit.

## Provenance and citation

The author-supplied reproducibility bundle used to initialize this repository is documented in `PROVENANCE.md`, including its SHA-256 checksum. The public-source processed METAR/SIROS files in that bundle are preserved here byte-for-byte.
